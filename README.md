# Macacangi Party — descargas 🍻

Juego de tablero 3D para carretear, con temática chilena.

Las versiones están en **[Releases](https://github.com/sebacondeza/macacangi-releases/releases/latest)**:

- `Macacangi-Party-Setup-<versión>.exe`: instalador para Windows (se actualiza solo).
- `Macacangi-Party-<versión>-portable.exe`: Windows sin instalar nada (también se actualiza solo).
- `Macacangi-Party-<versión>.AppImage`: Linux / Steam Deck.

Para jugar online, uno crea la sala y los demás se unen con su IP y el código. Si no están en la misma red, usen Tailscale, ZeroTier o Radmin VPN.

Este repo solo guarda los binarios; los publica automáticamente el workflow de compilación.
